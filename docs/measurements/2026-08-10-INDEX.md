# The 2026-08-10 analysis: what is in each file

Everything the preprint quotes comes from a file here. The 1.55 TB of
checkpoints and the 5 GB corpus these were computed from are **not** committed
and are not needed to redraw any figure or recompute any table.

## Results and analysis

| file | contents |
| --- | --- |
| `2026-08-10-full-study-results.md` | The compact results record: headline, per-arm displacement, noise floor, both registered contrasts, manipulation check, trajectory, robustness, replication. |
| `2026-08-10-barrier-analysis.json` | Section 8.4's headline metric. Per-arm displacement from the seed-matched twin, the 28-pair twin-vs-twin floor, the primary contrast, and the secondary reported as uncomputable. |
| `2026-08-10-analysis-heldout_loss.json` | The same panel on held-out loss, produced by `scripts/analysis.py`. Includes the twin-vs-twin floor derived per-seed and both registered contrasts. |
| `2026-08-10-validation.json` | The two validation runs: the 2048-window precision check (8 pairs, against their 512-window values) and the replication of the arm-vs-arm barrier on different hardware (8 seeds). |

## Data behind the figures

| file | contents |
| --- | --- |
| `2026-08-10-barrier-curves.json` | Every plotted point of both figures. All 24 arm-vs-twin and 28 twin-vs-twin interpolation curves (21 alphas each, with `max_excess` and `l2_raw`), all 32 held-out losses, and the per-step divergence bands. |
| `2026-08-10-training-curves.npz` | Per-step loss and pre-clip gradient norm for all 32 runs, all 9,536 steps, `float32`. Use this to redraw the trajectory at any resolution or to compute divergence over any step range. Arrays: `runs`, `step`, `loss`, `pre_clip_grad_norm`, `README`. |

## Did any of it stick? (exploratory)

| file | contents |
| --- | --- |
| `2026-08-10-stimulus-probe.json` | Per-model scores of the three stimulus texts under every final checkpoint: per-token loss over the injected region, 16 minimal-pair continuations, 4 name-bigram probes. Every model is scored on **all three** texts, which is what enables the difference-in-differences. |
| `2026-08-10-stimulus-analysis.json` | The same, paired within seed against the seed-matched control, with the difference-in-differences that separates "learned this passage" from "drifted in a way that helps on any passage". |

## The intervention and its provenance

| file | contents |
| --- | --- |
| `2026-08-10-injection-step.json` | Everything recorded at step 200 for all 32 runs: full-batch loss, pre-clip gradient norm, learning rate, batch slot, micro-index, row, and — for the 24 injecting runs — the **per-token losses over the 194-token injected region**. |
| `2026-08-10-step199-digests.json` | SHA-256 over the weight tensors of the last checkpoint before injection, all 32 runs. The check that makes the counterfactual exact: within a seed every condition has one identical parent, across two machines. |
| `2026-08-10-run-provenance.json` | One row per run: commit, branch, dirty flag, host, wall clock, resumes, final state digest, precision, batch shape, checkpoint count. |
| `2026-08-10-corpus-attestation-counts.json` | Independently re-counted occurrences of every entity named in the injected passages, split training / held-out, plus the four attested occurrences with the claim each corroborates and the containing-document token counts. |
